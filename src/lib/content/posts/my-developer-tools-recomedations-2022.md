---
title: My web development tools for 2022
date: 2022-02-02
---

These are the web development tools I picked up in 2021 and kept using in 2022.

- [Vite](https://vitejs.dev/) starts fast and stays out of my way.
- [SvelteKit](https://kit.svelte.dev/) is my favourite framework for building web applications.
- [GitHub Copilot](https://copilot.github.com/) is useful when I know what I want to write and need help with the repetitive parts.
- [Storybook for Svelte](https://storybook.js.org/blog/storybook-for-svelte/) gives components a proper place to develop and test.
- [Chromatic](https://www.chromatic.com/) publishes Storybook and catches visual changes during review.
- [Cloudflare](https://www.cloudflare.com/en-ca/) makes edge hosting straightforward.
- [Cypress](https://www.cypress.io/) offers a pleasant workflow for browser tests.
