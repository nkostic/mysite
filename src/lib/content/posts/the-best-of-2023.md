Some years pack in more change than others. For me, 2023 was one of them. These are the tools and ideas that held my attention as a web developer.

## Svelte and SvelteKit

<img src="/rundown2023/svelte.png" alt="Svelte logo on an orange background">

I enjoy the breadth of the JavaScript world. React, Vue, Angular, and Qwik all have good ideas, but Svelte remains the library I most enjoy using.

Svelte 4 arrived in June with fewer dependencies, smaller packages, and faster builds. The team also refreshed the documentation and learning tools at [svelte.dev](https://svelte.dev), [kit.svelte.dev](https://kit.svelte.dev), and [learn.svelte.dev](https://learn.svelte.dev/).

```bash
npx svelte-migrate@latest svelte-4
```

The first Svelte 5 preview introduced runes, Svelte's approach to explicit reactivity. It reminded me of the parts of KnockoutJS that felt ahead of their time.

SvelteKit 2 also arrived with Vite 5 support and shallow routing through `pushState` and `replaceState`.

```sh
npx svelte-migrate sveltekit-2
```

<img src="/rundown2023/sveltekit.png" alt="SvelteKit logo">

Shallow routing can improve interfaces such as mobile dialogs because it updates browser history without loading a new page.

```html
<script>
  import { pushState } from '$app/navigation';
  import { page } from '$app/stores';
  import Modal from './Modal.svelte';

  function showModal() {
    pushState('', { showModal: true });
  }
</script>

{#if $page.state.showModal}
  <Modal close={() => history.back()} />
{/if}
```

## TypeScript

TypeScript helps me catch mistakes before they reach a browser. Version 5 added standard decorators, which make patterns such as method logging easier to express.

```ts
function loggedMethod(originalMethod: any, _context: any) {
  function replacementMethod(this: any, ...args: any[]) {
    console.log("LOG: Entering method.");
    const result = originalMethod.call(this, ...args);
    console.log("LOG: Exiting method.");
    return result;
  }

  return replacementMethod;
}

class Person {
  constructor(public name: string) {}

  @loggedMethod
  greet() {
    console.log(`Hello, my name is ${this.name}.`);
  }
}
```

Daniel Rosenwasser's [TypeScript 5.0 announcement](https://devblogs.microsoft.com/typescript/announcing-typescript-5-0/) explains the change in detail. Axel Rauschmayer also wrote a useful [decorator overview](https://2ality.com/2022/10/javascript-decorators.html).

## Playwright

<img src="/rundown2023/playwright.png" alt="Playwright logo">

[Playwright](https://playwright.dev/) is my favourite browser automation tool. I use it for component tests and full end-to-end suites. The visual test runner added in 2023 made debugging much easier.

<img src="/rundown2023/playwrightui.png" alt="Playwright test runner">

## Browsers

<img src="/rundown2023/Browsers2023.png" alt="Browser logos used in 2023">

I used Arc to organize everyday browsing, Brave for research, and Edge for much of my development work. Chrome and Firefox remained essential test targets. WebKit also had a strong year, especially for new CSS support.

Jen Simmons covered the most useful WebKit changes in her [WWDC23 session](https://developer.apple.com/videos/play/wwdc2023/10121/).

[shadcn/ui](https://ui.shadcn.com/) became my preferred way to build reusable components with [Tailwind CSS](https://tailwindcss.com/). I also enjoyed seeing the Svelte community build [shadcn-svelte](https://www.shadcn-svelte.com/).

## Figma and Photoshop

<img src="/rundown2023/figmap.png" alt="Figma interface">

Figma remained my main design and prototyping tool. Photoshop's new AI tools also convinced me to keep my subscription after I had considered replacing it.

## Node and Bun

<img src="/rundown2023/nodejs-logo-svgrepo-com.svg" alt="Node.js logo">

Several old Node.js releases reached end of life in 2023, while versions 18 and 20 became the practical choices for current projects.

Bun 1.0 also arrived. Its startup speed, built-in TypeScript support, and SQLite integration made it fun to use for small experiments.

<img src="/rundown2023/bunlogo.svg" alt="Bun logo">

## GitHub, VS Code, and Copilot

<img src="/rundown2023/githubcopilot.webp" alt="GitHub Copilot interface">

GitHub is still one of my favourite places on the web because I can learn directly from working code. VS Code remains my main editor. I use the [VSCode Neovim extension](https://github.com/vscode-neovim/vscode-neovim) to practise keyboard-driven editing and [GitHub Copilot](https://copilot.github.com/) for repetitive code.

<img src="/rundown2023/vscode.png" alt="Visual Studio Code logo">

## Large language models

<img src="/rundown2023/chatgpt.png" alt="ChatGPT interface">

Large language models moved from research demos into my daily work in 2023. I used ChatGPT for drafting, debugging, and exploring unfamiliar topics. It was useful, but its confident mistakes meant I still had to check the output carefully.

Meta's LLaMA release also made capable language models available to more researchers and developers. Andrej Karpathy's [introduction to large language models](https://www.youtube.com/watch?v=zjkBMFhNj_g) is an excellent explanation of how they work.

## On to 2024

This list could have been much longer, but these were the parts of 2023 that stayed with me. I am curious to see which of them still matter a year from now.
